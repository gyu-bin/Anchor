# App Store Review Notes (Keyring 1.0.1+)

Paste the **English** block into App Store Connect → App Review Information → Notes.

## English (Review Notes)

**Device:** iPhone only (not optimized for iPad in this version).

**What makes Keyring different:** Apps stay blocked until the user finishes today’s routine checklist—not a fixed timer-only blocker.

**Quick test path:**
1. Complete the in-app guide (or skip if already done).
2. Open **Routine** tab → create a routine (e.g. “Morning”) with 1–2 tasks and select apps to block (e.g. Safari) via Screen Time picker.
3. Allow **Family Controls / Screen Time** when prompted (Settings → Screen Time permission).
4. Open **Today** tab → check off tasks; when all tasks for an active routine are done, restrictions lift automatically.
5. **History** shows completion calendar; **Settings** has appearance and guide replay.

**IAP:** One-time “Full access” purchase (no subscription). Sandbox account attached if required.

**Contact:** [your email]
