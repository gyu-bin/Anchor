## Connect 메타데이터 v2

**부제목 (30자 이내)**  
루틴 끝낼 때까지 앱·웹 잠금

**홍보 텍스트 (170자 · 116자)**  
시간만 막는 차단 앱이 아니에요. 오늘 루틴 할 일을 모두 끝낼 때까지 선택한 앱·웹만 잠기고, 완료하면 바로 풀려요. 14일 전체 기능 무료 체험 · 구독 없이 ₩7,900 평생 1회. 즉시잠금·기록·위젯.

**설명 — 앞부분 (복사용)**

```
키링은 「시간만 막는 차단 앱」이 아니라, 오늘 루틴 할 일을 모두 끝낼 때까지 선택한 앱·웹만 잠기는 루틴 앱이에요.

• 할 일 완료 → 잠금 해제: 오늘 탭에서 체크리스트를 다 하면 Screen Time 잠금이 바로 풀려요.
• 나만의 루틴: 아침·저녁 반복, 시작 시간, 차단할 앱·사이트, 쉬는 날, 마감 연장.
• 빠른 잠금: 루틴 없이 지금 바로 N분 동안 앱을 잠글 수 있어요.

처음 14일은 전체 기능을 무료로 써요. 이후에는 무료 한도(루틴 3개 등)가 적용되며, 구독 없이 ₩7,900 한 번 결제로 평생 전체 기능을 열 수 있어요.
```
